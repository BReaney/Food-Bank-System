# Archived milestone note — early booking demo

> **Outdated implementation instructions.** This file is retained as a short pointer for people following earlier milestones. The original early-stage instructions for `ENABLE_DEMO_BOOKING` and an unauthenticated hardcoded booking flow are **no longer applicable** to the current application.

The working prototype now uses:

- **Authenticated fictional accounts** with sessions and staff/student roles.
- **Term-based survey and staff enrollment checks** before booking.
- **Transactional appointment creation, cancellation and rescheduling**.
- **Private in-app notices and preserved booking event history**.
- **Separate student and staff pages**.

To set up the current version, use:

1. [Root README — run locally](../README.md#run-locally)
2. [Database setup](../database/README.md)
3. [Appointment management design](../docs/appointment-management.md)
4. [Testing and verified results](../testing/README.md)
